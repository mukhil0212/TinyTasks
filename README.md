# TinyTasks

A React Native Expo application with Supabase authentication.

## Security Notice

⚠️ **Important:** This repository contains a known security issue with exposed OAuth client secrets. Please review the [SECURITY.md](./SECURITY.md) file for details and recommended fixes before deploying to production.

**Critical Issue:** The Nylas OAuth client secret is currently exposed in the client-side code. This needs to be moved to a backend service before production use.
